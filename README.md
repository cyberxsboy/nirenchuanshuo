**Nirenchuanshuo** is an independent website sharing practical technology resources, AI-related tutorials, programming knowledge, website development guidance, and technical troubleshooting articles.

Official website: **[https://nirenchuanshuo.com/](https://nirenchuanshuo.com/)**

## About This Repository

This repository provides a public reference for the Nirenchuanshuo website and organizes related technical documentation, examples, and learning resources.

The website and this repository are independently hosted. The repository is not a GitHub Pages mirror of the website.

## How to Use This Repository

1. Browse the documentation directories by topic.
2. Read the relevant guide before applying a configuration or code example.
3. Check the source documentation and software versions when troubleshooting.
4. Report reproducible documentation issues through GitHub Issues when enabled.

## Documentation Principles

- Prefer practical, verifiable technical explanations.
- Keep instructions consistent with the software versions being discussed.
- Distinguish tested procedures from general suggestions.
- Remove credentials, tokens, private server details, and personal information from examples.
- Link to relevant official documentation when appropriate.
