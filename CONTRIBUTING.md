# Contributing

Thank you for helping improve the Nirenchuanshuo technical documentation.

## Guidelines

- Submit clear, specific, and reproducible corrections.
- Include relevant software versions when reporting technical issues.
- Do not publish passwords, API keys, personal information, or private server details.
- Use descriptive filenames and headings.
- Link to relevant official documentation when appropriate.
- Avoid duplicate articles and unrelated promotional content.

## Reporting an Issue

When reporting a documentation issue, include:

1. The affected file or section.
2. What is incorrect or unclear.
3. Steps to reproduce the problem, if applicable.
4. The expected result and relevant environment information.

## Pull Requests

Keep changes focused and explain the reason for each proposed improvement.
